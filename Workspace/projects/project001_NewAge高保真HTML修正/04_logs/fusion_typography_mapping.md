# 《融合》中文排版映射

从《绿色三角洲：融合》汉化 PDF 的实际文字层统计得到以下主要规则：

| 用途 | 《融合》PDF | New Age HTML |
|---|---|---|
| 正文 | FandolSong Regular，10.91 pt | FandolSong Regular，10.9 pt |
| 正文粗体 | FandolSong Bold，10.91 pt | FandolSong Regular 合成粗体，10.9 pt |
| 次级标题 | FandolSong Bold，12.95 pt | FandolSong Regular 合成粗体，13 pt |
| 红色章节标题 | 方正兰亭刊黑简体，14.94 pt | 方正兰亭刊黑简体，15 pt |
| 大标题 | 方正字迹-牟氏美隶简体，21.92-29.89 pt | 方正字迹-牟氏美隶简体，22-30 pt |
| 特殊叙述文字 | FandolKai Regular，10.91 pt | FandolKai Regular，10.9 pt |
| 页眉 | 方正字体，约 10.96 pt | 方正兰亭刊黑简体，11 pt |

作者行使用方正兰亭刊黑简体，在 HTML 中对应 DG Noto Sans SC。PDF 文字层受页面缩放影响，正文基线间距约为 17-18 pt；结合汉化制作者提供的 16-17 左右信息，HTML 采用 17 pt。段落边界和首行缩进沿用原 PDF 的结构信息。

字体来自用户提供的合法授权完整文件，并已转换为 WOFF2 随 HTML 资源打包。Noto Serif SC 和 Noto Sans SC 保留为缺字备用字体。
