# 开发计划

1. 固定输入和视觉基线 -> 核对哈希、页数和输入身份，复现 5 处溢出。
2. 修状态正确性 -> 页码范围与配置签名、损坏断点、单层重试均有回归测试。
3. 修产物契约 -> 候选文件验收后原子发布，DOM 块覆盖与字体检查可自动失败。
4. 修 Rejection 通用排版 -> 对照原件与人工排版参考，消除 5 处溢出，不删信息，保留旋转和强调样式。
5. 拆内容与高保真职责 -> 分离浏览器契约、可见性、质量检查；普通文档不再猜跨页或删重复句。
6. Review 与全量验收 -> 逐页检查 25 页、运行全量测试、检查无关差异并更新记录。
