# 全局复利与踩坑日志

本文件用于记录犯过的错误、踩过的坑、走过的弯路，以及未来可以复用的方法。

## 使用规则

1. 不记录流水账，只记录能避免未来重复犯错的内容。
2. 每条记录要写清楚：发生了什么、为什么错、怎么修、以后怎么避免。
3. 如果某条经验会影响新项目流程，要同步更新 `02_NEW_PROJECT_SOP.md`。
4. 如果某条经验会影响 Codex 行为，要同步更新 `00_GLOBAL_WORKBENCH.md`。

## 记录模板

```text
### YYYY-MM-DD｜标题

- 场景：
- 问题：
- 原因：
- 修正：
- 以后复用的方法：
- 需要同步更新的文档：
```

## 日志

### 2026-06-16｜失败页与重翻页被互相覆盖

- 场景：PDF 翻译项目中，同时勾选“只重试失败页”并填写手动重翻页。
- 问题：手动重翻页被清掉旧译文，但没有进入翻译队列。
- 原因：任务页选择只取失败页，没有把失败页和重翻页合并。
- 修正：把实际任务页改为失败页与重翻页的并集。
- 以后复用的方法：凡是两个筛选条件都可能产生任务页时，先明确它们是交集、并集还是覆盖关系，再写代码。
- 需要同步更新的文档：无。

### 2026-06-16｜普通加号被误判成表格分隔线

- 场景：PDF 提取中，`10+ hours`、`4+ Health damage` 这类正文被识别成表格。
- 问题：Word/HTML 里普通段落被拆成表格。
- 原因：表格分隔线规则把普通 `+` 当成了强表格信号。
- 修正：收紧表格分隔线判断，普通加号不再触发表格。
- 以后复用的方法：格式识别只能使用强信号；普通正文符号不能单独作为结构判断依据。
- 需要同步更新的文档：无。

### 2026-06-16｜目录代码围栏挤在同一行导致泄漏

- 场景：目录页译文出现 `标题```toc条目` 挤在同一行。
- 问题：HTML/Word 导出没有识别目录围栏，导致 ` ```toc ` 显示到正文。
- 原因：导出器只识别独占一行的目录围栏。
- 修正：导出前规范化内联目录围栏，把它拆回标准多行格式。
- 以后复用的方法：导出器需要先做标记规范化，再做结构渲染。
- 需要同步更新的文档：无。

### 2026-06-17｜PowerShell 读中文文件要指定 UTF-8

- 场景：检查 `context.md` 和全局工作台文档。
- 问题：中文内容显示成乱码。
- 原因：PowerShell 没有按 UTF-8 读取 Markdown。
- 修正：改用 `Get-Content -Encoding UTF8` 重新读取。
- 以后复用的方法：读取项目中文 Markdown 时明确指定 UTF-8。
- 需要同步更新的文档：无。

### 2026-06-17｜上传文件用随机名会重复占空间

- 场景：Web 端多次上传同一本 PDF。
- 问题：同一 PDF 被保存成多个随机文件，`uploads/` 快速膨胀。
- 原因：上传文件名使用 uuid 后缀，没有按内容去重。
- 修正：保存上传文件前计算 SHA256，已存在相同内容时直接复用。
- 以后复用的方法：大文件缓存应优先按内容 hash 去重，随机名只适合临时小文件。
- 需要同步更新的文档：无。

### 2026-06-25｜PowerShell 后台服务日志不能重定向到同一文件

- 场景：启动 Streamlit 做界面截图检查。
- 问题：`Start-Process` 同时把 stdout 和 stderr 指向同一个日志文件时直接失败。
- 原因：PowerShell 不允许 `RedirectStandardOutput` 和 `RedirectStandardError` 使用相同目标。
- 修正：分别写入 `.out.log` 和 `.err.log`。
- 以后复用的方法：Windows 后台服务启动时，stdout/stderr 分开重定向；需要合并时后续再读两个文件。
- 需要同步更新的文档：无。

### 2026-06-25｜Playwright 浏览器版本要匹配调用端

- 场景：用 `node_repl` 调 Playwright 做 Streamlit 截图检查。
- 问题：项目虚拟环境装过 Chromium，但 `node_repl` 仍提示找不到浏览器。
- 原因：Python Playwright、npx Playwright 和 `node_repl` 内置 Playwright 版本不同，浏览器目录不通用。
- 修正：先读取 `node_repl` 中 Playwright 的版本，再用 `npx playwright@版本 install chromium` 安装匹配浏览器。
- 以后复用的方法：截图检查前先确认实际调用端的 Playwright 版本，不要假设其它环境装过的浏览器可复用。
- 需要同步更新的文档：无。
