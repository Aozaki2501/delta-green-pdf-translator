# KULT 高保真 HTML 开发计划

日期：2026-07-29

## 当前实施状态

- 已完成 KULT / DG 独立排版配置、界面切换和翻译提示隔离。
- 已修复第 70、100、101 页图片身份匹配；120 页结构提取完整通过。
- 已完成红色正文与小标题的区分、首字下沉翻译前合并。
- 已完成章节开篇双行标题合并、`full_width_hero` 模板与中部插画的 `image_float` 语义；第 6、7 页短中文占位截图无溢出。
- 图册页维持 `ART` 固定视觉层，不生成正文栏；仍需用真实译文完成代表页与全书视觉验收，当前不能宣称 KULT 已达到高保真交付。


## 1. 目标与边界

目标是让当前项目能够稳定处理 KULT 规则书和模组，输出中文高保真 HTML，同时不破坏现有 Delta Green 流程。

本计划使用两份参考资料：

- 原版：《KULT - DFG - Avgrunden Scenariosamling》，120 页。
- 中文排版参考：《往昔回响》，27 页。

两份 PDF 不是原文与译文的逐页对应版本。《往昔回响》只能用于参考成熟的 KULT 中文字体、字号、密度和主题处理，不能用于校对《Avgrunden》的页面坐标或翻译内容。

默认目标采用“忠实原版”：

- 保留《Avgrunden》的页面尺寸、插画、栏结构、红黑配色和视觉层级。
- 中文字体、行距和密度参考《往昔回响》。
- 不 OCR、不翻译插画内部文字。
- 不强求中文复刻拉丁装饰字体的具体字形，只复刻其视觉角色。

后续可增加“中文 KULT 主题”，使用《往昔回响》式羊皮纸、金黑边框和黑底附录；它不属于第一版验收范围。

## 2. 参考资料结论

### 2.1 《Avgrunden》原版

- 页面尺寸约 479.1 × 677.5 pt，120 页。
- 正文以 7.8 pt Alverata 为主，常见双栏和三栏。
- 主要颜色为近黑 `#231f20`、暗红 `#b8282f` 和蓝色 `#0066b3`。
- 具有章节大图、首字下沉、图片侵入栏位、文字绕图、跨栏标题、版权信息网格和黑底插画附录。
- 第 2、3、4、13、21、69、99、116-120 页没有普通文字层，属于空白页或插画页。
- 当前解析在第 70、100、101 页已确认会因图片身份匹配失败而中止。

### 2.2 《往昔回响》中文排版

- 页面尺寸约 595.2 × 793.6 pt，27 页。
- 中文正文以 8.5-9 pt 宋体为主，标题使用红色粗体或装饰字体。
- 普通页面采用纸张纹理、金黑边框、双栏正文和固定页脚。
- 具有封面、章节开篇、普通双栏、中央插图绕排、角色资料页、表格式规则页和黑底附录。
- PDF 内包含方正等字体。项目不得直接提取并重新分发授权不明的字体；默认使用开源字体，允许用户自行提供已授权字体。

## 3. 成功标准

第一版必须同时满足：

1. 《Avgrunden》120 页结构提取全部完成，不出现图片身份错误。
2. 每个可翻译文本块恰好对应一个译文块。
3. 首字下沉不再从正文单词中拆走字符。
4. 双栏、跨栏、绕图、章节开篇和黑底插画页都使用明确的布局类型。
5. HTML 中没有文字裁切、重叠、越界或低于配置下限的静默缩字。
6. 插画资源、位置和裁切范围与原 PDF 一致。
7. 未翻译的瑞典语正文会导致任务失败；专名和允许保留词除外。
8. Delta Green 现有高保真样本与全量测试不退化。

“高保真”指页面结构、插画、栏关系、颜色、间距和字体层级保持一致，不指中文字形与原拉丁装饰字体完全相同。

## 4. 目标架构

### 4.1 通用核心

继续负责：

- PDF 页面、文字、图片、矢量和坐标提取。
- 稳定的内容块 ID 与阅读顺序。
- 翻译任务、断点续传和质量检查。
- 固定页面 HTML 与阅读版 HTML 输出。
- 浏览器渲染后的溢出和资源检查。

通用核心不得包含 Delta Green 或 KULT 的专用术语和视觉常量。

### 4.2 游戏配置

新增配置层：

```text
profiles/
  generic.yaml
  delta_green.yaml
  kult.yaml
```

每个配置至少包含：

- 游戏名称、源语言、目标语言。
- 翻译提示、保护词、规则缩写和默认术语表。
- 正文、标题、装饰标题、手写体、表格和页码的字体角色。
- 页面颜色、字号下限、行距、栏距和标题间距。
- 允许使用的页面布局和特殊区域。
- 源语言残留检查规则。

自动识别只能提出建议，最终配置必须由用户明确选择；不能在识别失败时静默使用 DG 配置。

### 4.3 页面中间模型

保留现有稳定 ID，扩充布局语义：

- `drop_cap`：与正文段落绑定的首字下沉。
- `full_width_hero`：章节开篇大图。
- `image_float`：侵入正文区域并参与绕排的图片。
- `credits_grid`：版权与制作人员网格。
- `art_gallery`：黑底插画图册页。
- `character_sheet`：人物资料和规则字段页面。
- `ornament`：只保留、不翻译的装饰字形或符号。
- `running_title`：非数字页眉页脚。

这些类型应成为结构化数据，不能只依赖 CSS 类名或针对页码的条件判断。

## 5. 开发阶段

### 阶段一：建立基准样本

预计 1-2 个开发日。

工作：

- 固定原版代表页：1、5-8、43-46、70-71、116-120。
- 固定中文参考页：1-6、14、20、26-27。
- 保存页面结构摘要、渲染截图和预期布局类型。
- 建立“文字层”“插画层”“装饰层”分层对照。

完成门槛：

- 每个代表页都有明确的页面类型、阅读顺序和允许偏差。
- 确认第一版只实现“忠实原版”，中文主题不混入核心验收。

### 阶段二：修复图片提取硬错误

预计 2-3 个开发日。

涉及：

- `core/page_structure.py`
- `tests/test_page_structure_images.py`

工作：

- 使用 PDF 图片 xref、原始编码数据、尺寸、变换矩阵和位置建立严格身份。
- 不再直接比较两种来源中含义不同的像素摘要。
- 多个候选仍然冲突时立即失败，并输出页码、xref、bbox 和摘要。
- 为第 70、100、101 页的图片结构建立回归夹具。

完成门槛：

- 120 页结构提取全部通过。
- 图片数量、位置、遮罩和资源摘要稳定。
- 不允许“选择最近图片”或忽略身份错误。

### 阶段三：引入游戏配置

预计 2-3 个开发日。

涉及：

- `core/typeset_models.py`
- `core/translator.py`
- `core/typeset_translation.py`
- `app.py`
- 新增 `core/game_profile.py`
- 新增 `profiles/*.yaml`

工作：

- 从 `TypesetConfig` 移出 DG 字体、颜色和字号常量。
- 从通用翻译提示中移出 Delta Green、FBI、SAN、MJ-12 等规则。
- KULT 配置声明瑞典语到中文、KULT 保护词和恐怖叙事风格。
- 界面增加游戏配置、源语言和主题选择。
- 高保真模式缺少指定字体时直接报告错误，不静默替换字体。

完成门槛：

- 同一核心可加载 `delta_green` 和 `kult`。
- 选择 KULT 后，发送给模型的提示中不出现 Delta Green 专用规则。
- 选择 DG 后，现有行为保持不变。

### 阶段四：扩充语义与阅读顺序

预计 3-5 个开发日。

涉及：

- `core/typeset_models.py`
- `core/semantic_analyzer.py`
- `core/layout_hints.py`
- `core/layout_adapters.py`
- `core/typeset_templates.py`

工作：

- 增加首字下沉、绕图、章节大图、制作人员网格、图册和人物资料语义。
- 首字下沉与所属段落共用一个翻译单元，翻译后再把首个汉字设为装饰。
- 读取图片作为文字流的障碍物，形成左右或多边形绕排区域。
- 识别非数字的页眉、页脚和运行标题。
- 标题颜色改为配置中的色板或容差规则，不再只匹配三个 DG 色值。
- 让 `layout_hints.special_regions` 真正改变内容模型和渲染行为。

完成门槛：

- 第 6 页首句完整。
- 第 7、43、45 页阅读顺序正确，文字不会穿过插画。
- 第 5 页制作人员信息不被当成普通连续正文。
- 第 116-120 页不会尝试生成正文栏。

### 阶段五：实现 KULT 渲染器和字体映射

预计 4-6 个开发日。

涉及：

- `exporters/typeset_html.py`
- `core/typeset_templates.py`
- 新增 `exporters/themes/kult.py` 或等价主题模块
- `assets/typeset_fonts/`

工作：

- 使用配置生成 CSS 变量，移除渲染器中的 DG 字体和颜色硬编码。
- 保留原版 479.1 × 677.5 pt 页面，不改成 A4。
- 建立 KULT 中文字体角色：
  - 正文：开源中文宋体。
  - 标题：开源中文黑体或可选用户字体。
  - 装饰标题：风格近似字体，不复制原版拉丁字形。
  - 手写或信件：开源楷体。
- 实现跨栏章节图、固定背景、黑底图册和图片绕排。
- 中文内容超出区域时产生明确错误报告，不静默裁切或无限缩字。

完成门槛：

- 代表页在 Chromium 中无裁切、重叠、缺字和资源丢失。
- 原图位置误差不超过 1 pt。
- 普通正文区域边界误差不超过 2 pt。
- 中文最小字号由 KULT 配置明确声明并受到检查。

### 阶段六：翻译完整性与视觉质量检查

预计 2-4 个开发日。

涉及：

- `core/translation_validation.py`
- `core/quality.py`
- `core/typeset_pipeline.py`
- 新增浏览器端布局检查脚本和测试

工作：

- 校验每个可翻译块都有且只有一个输出。
- 使用源块与译文的规范化相似度、允许保留词和术语表检查瑞典语原样返回。
- 不把人名、地名和 KULT 规则词中的拉丁字符一概判为漏翻。
- 浏览器检查元素实际边界、滚动溢出、遮挡、空白译文和缺失字体。
- 对插画层做遮罩后的截图差异检查；文字层按几何和可读性检查，不要求像素相同。
- 生成逐页问题报告，任何严重问题都会让任务失败。

完成门槛：

- 代表页全部通过自动检查和人工截图复核。
- 120 页全书输出完成，没有严重质量问题。
- 图片文字保持原样，不进入 OCR 或翻译任务。

### 阶段七：回归与交付

预计 2-3 个开发日。

工作：

- 运行 KULT 代表页、全书和 DG 现有样本。
- 运行项目全量测试。
- 检查离线重新导出、断点续传和失败页重试。
- 更新 README、配置说明和 KULT 示例。

完成门槛：

- KULT 与 DG 两套配置均可从界面完整运行。
- 旧 DG 项目无需修改配置即可继续使用。
- 文档明确区分“忠实原版”和“中文 KULT 主题”。

## 7. 工作量与提交方式

第一版预计 16-26 个开发日，建议按阶段独立提交：

1. 图片身份与 120 页提取。
2. 游戏配置与翻译提示解耦。
3. KULT 语义模型。
4. KULT 渲染主题。
5. 质量检查、全书验收和文档。

每个阶段必须先通过自己的代表页和回归测试，再进入下一阶段。不要先跑整本翻译来掩盖结构问题。

## 8. 第一轮实施范围

第一轮只完成阶段一和阶段二：

- 固化代表页。
- 修复第 70、100、101 页图片身份错误。
- 确认 120 页结构提取能够完整结束。

在这个门槛完成前，不开始调用翻译接口，也不开发 KULT 主题 CSS。
