# 导出重试与输出健康优化计划

## 目标

让翻译结果更可信：开关要真实生效，导出失败要拦住，失败后能只重试导出，历史记录要优先显示最新任务。

## 开发计划

1. 接通 PDF 模糊术语匹配。
   - 验证：新增测试确认 PDF 翻译器收到 AC 术语匹配器。

2. 普通 PDF 导出失败改为任务失败。
   - 验证：新增测试确认 HTML/Word 导出异常会抛出，不再静默完成。

3. Web 增加普通输出“重试导出”入口。
   - 验证：复用 `.progress.json`，只重新生成文件，不调用翻译 API。

4. 输出历史优先显示最新审计记录。
   - 验证：新增测试确认同一目录多个审计记录时，默认只展示最新任务状态。

5. 后续拆分大文件。
   - 验证：先不做大搬迁；等上述行为稳定后，再按小步拆 `app.py`、`typeset_html.py`、`extractor.py`。
